📋 REQUIRED DATA STRUCTURE
═══════════════════════════════════════════════════════════════════════════

Inference must return dict with this structure:

{
    "top_positive": {
        "aspect": str,
        "percentage": float,
        "positive": int,
        "neutral": int,
        "negative": int,
        "total": int
    },
    "top_negative": {
        "aspect": str,
        "percentage": float,
        "positive": int,
        "neutral": int,
        "negative": int,
        "total": int
    },
    "overall_sentiment_distribution": {
        "Positif": int,
        "Netral": int,
        "Negatif": int
    },
    "aspect_distribution": {
        "AspectName1": int,
        "AspectName2": int,
        ...
    },
    "aspects_detailed": [
        {
            "aspect": str,
            "positive_count": int,
            "neutral_count": int,
            "negative_count": int,
            "positive_reviews": [str, str, str],
            "neutral_reviews": [str, str, str],
            "negative_reviews": [str, str, str]
        },
        ...
    ]
}

🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Setup:
   python -m venv venv
   source venv/bin/activate  # or: venv\Scripts\activate on Windows
   pip install -r requirements.txt

2. Prepare Models:
   cp -r /path/to/ABSA_pertama/model ./model

3. Integrate Inference:
   - Edit inference_template.py → Fill TODO sections
   - Update app.py line ~530 → Replace sample_results with run_inference()

4. Run:
   streamlit run app_absa_integrated.py
   (Or rename to app.py and run: streamlit run app.py)

5. Access:
   Browser → http://localhost:8501

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: App runs but no results appear
Solution: Check if run_inference() returns correct dict structure
         Use validate_result_structure() to debug

Problem: "ModuleNotFoundError: No module named 'inference_template'"
Solution: Make sure both files in same directory
         Or: from .inference_template import run_inference

Problem: Plotly charts not rendering
Solution: pip install --upgrade plotly
         Clear browser cache

Problem: Models not loading
Solution: Check path to model files
         Print debugging info in _load_models()
         Verify safetensors files exist

Problem: File upload not working
Solution: Check file size (< 10MB)
         Check file type (.csv, .txt, .xlsx)
         Look at st.file_uploader documentation
